## 4주차 반응형 수정

## 확인 한 문제

- 다른 모바일 청첩장을 보면 visual 부분에 간단한 문구와 이미지를 배경으로 하면서 임팩트를 주는데 현재는 여백이 너무 좁아서 답답해 보인다.
- 모바일 화면에서 메뉴의 텍스트들이 깨졌다.
- 모바일 화면에서 제목 태그들의 글자가 너무 커서 화면이 답답하게 보였다.
- 모바일 화면에서 our history의 이미지가 너무 작아지고 1열에 3개, 2열에 1개의 너비를 가짐으로 정렬되지 않았다.
- 모바일 화면에서 버튼이 너무 작았다.

## 수정한 내용

- visual 섹션을 메뉴 높이를 제외한 viweport의 높이 만큼 설정했다.
- 모바일 화면에서 메뉴의 글자 크기를 줄이고 화면이 너무 길어지지 않게 2x2로 수정했다.
- 콘텐츠에 width와 max-width를 함께 사용했다.
- 기능 카드 목록과 메뉴를 반응형 grid로 변경했다.
- 499px 이하에서 카드 한 열로 구성했다.
- 모바일 화면에서 버튼과 글자 크기를 키웠다.
- 모바일 화면에서 input과 textarea의 최소 높이와 글자 크기를 키웠다.

## 달라진점

- 모바일 화면에서 visual 섹션이 넓게 보이면서 답답함을 해소했다.
- 메뉴가 viewport에 맞게 적절히 변경됐다.
- 제목 태그들이 viewport에 맞게 변경 되면서 답답하지 않고 가독성이 늘었다.
- our history의 이미지들이 모바일 화면에서 1자로 구성되면서 이미지가 더 잘보이게 됐다.
- input, textarea, button의 높이와 글자가 커지면서 모바일에서 더 잘 보이고 action이 용이해졌다.
