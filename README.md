# 모바일 청첩장 — 9주차 form validate 과제

## 추가·수정한 기능

- 방명록 입력 화면을 <form>으로 구성하고 단계별 검증을 추가했다.
- 필수 입력의 성공·오류 상태를 색상, 도움말, 글자 수로 표시한다.
- 등록 중 상태와 성공·실패 메시지를 제공한다.
- 등록한 방명록을 localStorage에 저장하고 다시 화면에 표시한다.
- 라이트·다크 모드의 공통 색상을 CSS 변수로 정리했다.

## 입력 조건

- 개인정보 수집에 동의해야 한다.
- 닉네임, 신랑·신부 관계, 세부 관계를 입력해야 한다.
- 세부 관계가 기타이면 기타 관계를 추가로 입력해야 한다.
- 축하 메시지는 10자 이상 300자 이하로 입력해야 한다.

## 확인 순서

동의 → 닉네임 → 관계 → 축하 메시지 → 입력 내용 확인 → 방명록 등록 순서로 확인한다.

## 실패 처리

- 입력 오류는 validateNickname(), validateRelation(), validateMessage()에서 검증하고 다음 단계 이동을 막는다.
- 저장 실패는 saveGuestbookEntries()의 반환값을 확인해 setSubmitState("error", ...)로 화면에 표시한다.

# 모바일 청첩장

## 사용자와 목표

- 사용자: 모바일 청첩장을 받은 하객
- 목적: 결혼식 정보와 두 사람의 이야기를 확인하고 축하 메시지를 남긴다.

## 7주차 결과물

7주차에는 개인정보 수집에 동의한 뒤 닉네임, 관계, 축하 메시지를 단계별로 입력하고 내용을 확인하여 전송하는 흐름을 구현했다. 입력값이 비었거나 필요한 항목을 선택하지 않은 경우 오류를 안내하고, 이전 단계 이동과 수정 및 다시 작성이 가능하도록 기능을 추가했다.

## 새로 추가한 기능

1. 축하 메시지 전송 흐름을 실제 모바일 청첩장의 방식을 착안하여 방명록 등록 기능으로 명칭을 변경하고, 입력 단계를 모달형식으로 변경하였다. 그리고 작성한 내용이 기존 방명록 목록 아래에 바로 추가되도록 했다.
2. Our History의 사진을 클릭하면 선택한 사진을 확대 모달로 확인하고 닫을 수 있는 기능을 추가했다.

## 새 기능

### 1. 방명록 등록

- 사용자 행동: 방명록 남기기 버튼을 누르고 모달에서 정보 수집에 동의한 뒤 닉네임, 관계, 축하 메시지를 입력한다.
- 조건: 정보 수집 동의 여부, 닉네임 입력 여부, 신랑 또는 신부 선택 여부, 세부 관계 선택 여부, 축하 메시지 입력 여부를 확인한다. 세부 관계에서 기타를 선택하면 기타 관계도 입력했는지 확인한다.
- 성공: 모든 값을 입력하고 방명록 등록하기를 누르면 입력한 닉네임, 관계, 메시지가 기존 방명록 목록의 마지막에 추가되고 완료 화면이 표시된다.
- 오류: 필수 값이 입력되지 않으면 에러 문구를 표시하고 다음 단계로 이동하지 않는다. 정보 수집에 동의하지 않으면 다음 버튼이 비활성화된다.
- 취소: 모달의 닫기 버튼을 누르면 모달을 닫고 매안 화면을 보여준다.
- 수정: 내용 확인 화면에서 수정하기를 누르면 입력한 값을 유지한 채 닉네임 입력 단계로 돌아간다.
- 다음 행동: 등록 완료 화면에서 방명록 확인하기를 누르면 모달이 닫히고 새 항목이 추가된 방명록을 확인할 수 있다.

### 2. Our History 사진 확대

- 사용자 행동: Our History에서 원하는 탭을 선택한 뒤 표시된 사진을 클릭한다.
- 조건: 현재 선택한 탭에 표시된 사진의 경로와 설명을 확인한다.
- 성공: 클릭한 사진과 같은 사진이 확대 모달에 표시된다.
- 취소: 확대 모달의 우측 상단 닫기 버튼을 누르거나 Esc 키를 누르면 모달이 닫힌다.
- 다음: 모달을 닫은 뒤 다른 탭을 선택하여 다른 사진을 확인하거나 방명록 작성 흐름을 계속할 수 있다.

## 테스트 기록

- 정상 경로: 동의 후 닉네임, 관계, 메시지를 모두 입력하고 등록했을 때 입력한 내용이 방명록 목록 아래에 추가되는지 확인한다.
- 오류:
  - 동의: 정보 수집에 동의하지 않았을 때 다음 버튼이 비활성화되는지 확인한다.
  - 입력: 닉네임, 관계 또는 메시지가 비어 있을 때 에러 문구가 표시되고 현재 단계에 머무르는지 확인한다.

- 취소: 작성 중 우측 상단 닫기 버튼을 누르면 모달이 닫히는지 확인한다.
- 사진 확대:
  - 정상: 각 탭의 사진을 클릭했을 때 선택한 사진이 모달에 표시되는지 확인한다.
  - 취소: 닫기 버튼을 사용했을 때 확대 모달이 닫히는지 확인한다.
