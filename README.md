# 모바일 청첩장

## 사용자와 목표

- 사용자: 모바일 청첩장을 받은 하객
- 목표: 결혼식 정보를 보고 방명록에 축하 메시지를 남긴다.

## 새로 추가한 기능

기존 축하 메시지 작성 흐름을 방명록 기능으로 변경했다. 작성 버튼을 누르면 모달 안에서 정보를 입력하고, 등록한 내용은 기존 방명록 목록 아래에 바로 추가된다.

## 사용자의 흐름

1. 방명록 남기기 버튼을 눌러 모달을 연다.
2. 정보 수집에 동의하고 다음 버튼을 누른다.
3. 이름이나 닉네임을 입력한다.
4. 신랑, 신부와의 관계와 세부 관계를 선택한다.
5. 축하 메시지를 입력하고 내용을 확인한다.
6. 방명록을 등록하면 작성한 내용이 목록 아래에 추가된다.

## 인터렉션 시나리오

1. 시작과 개인정보 수집 동의

- 행동, 이벤트: 방명록 남기기 버튼을 누르고 모달에서 정보 수집 동의 체크박스를 선택한다.
- 조건: 체크박스 선택 여부
- 반응, 다음 상태: 동의 전에는 다음 버튼을 누를 수 없다. 동의하면 다음 버튼이 활성화되고 이름 입력 단계로 이동할 수 있다.

2. 이름 또는 닉네임 입력

- 행동, 이벤트: 이름이나 닉네임을 입력하고 다음 버튼을 누른다.
- 조건: 입력값이 비어 있는지 확인
- 반응, 다음 상태: 값이 없으면 안내 문구를 보여 주고, 값이 있으면 관계 선택 화면으로 이동한다.

3. 관계 선택

- 행동, 이벤트: 신랑 또는 신부를 고르고 세부 관계를 선택한다.
- 조건: 관계와 세부 관계를 선택했는지 확인. 기타를 선택한 경우에는 관계를 직접 입력했는지도 확인
- 반응, 다음 상태: 필요한 값이 없으면 안내 문구를 보여 주고, 모두 입력했으면 메시지 입력 화면으로 이동한다.

4. 축하 메시지 입력

- 행동, 이벤트: 축하 메시지를 입력하고 내용 확인하기를 누른다.
- 조건: 300자 이내로 메시지를 입력했는지 확인
- 반응, 다음 상태: 값이 없으면 안내 문구를 보여 주고, 값이 있으면 내용 확인 화면으로 이동한다.

5. 내용 확인

- 행동, 이벤트: 입력한 내용을 확인하고 수정하기 또는 메시지 전송하기를 누른다.
- 조건: 입력한 내용이 맞는지 확인
- 반응, 다음 상태: 수정하기를 누르면 기존 값을 유지한 채 닉네임 입력 단계로 돌아간다. 방명록 등록하기를 누르면 작성한 내용이 목록 아래에 추가되고 완료 화면으로 이동한다.

6. 완료와 방명록 확인

- 행동, 이벤트: 완료 화면에서 방명록 확인하기를 누른다.
- 조건: 등록이 완료되었는지 확인
- 반응, 다음 상태: 모달이 닫히고 새 메시지가 추가된 방명록 목록으로 이동한다. 새로고침하면 사용자가 추가한 항목은 사라지고 기본 항목 두 개만 표시된다.

## 테스트 기록

- 정상 경로: 동의 후 이름, 관계, 메시지를 입력하고 등록했을 때 방명록 목록 아래에 입력한 내용이 추가되는지 확인한다.
- 동의하지 않은 경로: 정보 수집에 동의하지 않으면 다음 버튼이 비활성화되는지 확인한다.
- 입력 오류 경로: 이름, 관계 또는 메시지를 입력하지 않았을 때 안내 문구가 표시되고 현재 단계에 머무르는지 확인한다.
- 수정 경로: 내용 확인 화면에서 수정하기를 누르면 입력한 값이 유지된 채 닉네임 입력 단계로 돌아가는지 확인한다.

## 배포 주소

- 배포된 웹페이지 주소: 배포 후 입력
