# 모바일 청첩장

## 사용자와 목표

- 사용자: 모바일 청첩장을 받은 하객
- 목표: 결혼식 정보를 보고 축하 메시지를 남긴다.

## 사용자의 흐름

1. 개인정보 수집에 동의하고 메시지 보내기를 누른다.
2. 이름이나 닉네임을 입력한다.
3. 신랑, 신부와의 관계와 세부 관계를 선택한다.
4. 축하 메시지를 입력한다.
5. 입력한 내용을 확인하고 전송한다.
6. 전송을 완료하거나 메시지를 다시 작성한다.

## 인터렉션 시나리오

1. 시작과 개인정보 수집 동의

- 행동, 이벤트: 동의 체크박스를 선택하고 메시지 보내기를 누른다.
- 조건: 체크박스 선택 여부
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 버튼을 누르면 확인창이 열린다. 돌아가기를 누르면 동의가 해제되고, 동의하고 메시지 남기기를 누르면 이름 입력 화면으로 이동한다.

2. 이름 또는 닉네임 입력

- 행동, 이벤트: 이름이나 닉네임을 입력하고 다음 버튼을 누른다.
- 조건: 입력값이 비어 있는지 확인
- 반응, 다음 상태: 값이 없으면 안내 문구를 보여 주고, 값이 있으면 관계 선택 화면으로 이동한다.

3. 관계 선택

- 행동, 이벤트: 신랑 또는 신부를 고르고 세부 관계를 선택한다.
- 조건: 관계와 세부 관계를 선택했는지 확인. 기타를 선택한 경우에는 관계를 직접 입력했는지도 확인
- 반응, 다음 상태: 필요한 값이 없으면 안내 문구를 보여 주고, 모두 입력했으면 메시지 입력 화면으로 이동한다.

4. 축하 메시지 입력

- 행동, 이벤트: 축하 메시지를 입력하고 내용 확인하기를 누른다.
- 조건: 300자 이내로 메시지를 입력했는지 확인
- 반응, 다음 상태: 값이 없으면 안내 문구를 보여 주고, 값이 있으면 내용 확인 화면으로 이동한다.

5. 내용 확인

- 행동, 이벤트: 입력한 내용을 확인하고 수정하기 또는 메시지 전송하기를 누른다.
- 조건: 입력한 내용이 맞는지 확인
- 반응, 다음 상태: 수정하기를 누르면 입력값을 초기화하고 처음으로 돌아간다. 메시지 전송하기를 누르면 완료 화면으로 이동한다.

6. 완료와 다시 보내기

- 행동, 이벤트: 완료 화면에서 다시 보내기를 누른다.
- 조건: 메시지를 다시 작성할지 확인
- 반응, 다음 상태: 입력값을 모두 초기화하고 이름 입력 화면으로 이동한다.
